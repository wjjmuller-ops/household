Notifications

Popup Notifications

Turn on browser notifications to receive reminders while the app is open.

Notifications will show for:
  • Calendar events starting within 30 minutes
  • Overdue to-do items
  • Tasks assigned to the logged-in user

Status

Important

This first version checks notifications only while the web app is open in the browser. The next step is a service worker so notifications can work more like a mobile app.

If the test does not show, use http://127.0.0.1:5000 locally. Install and notifications work best on HTTPS or localhost. For phones, deploy to Render or another HTTPS host.
